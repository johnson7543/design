## Verification

- The [implementation Verify run](https://github.com/johnson7543/design/actions/runs/39061800605)
  and [manual release verification](https://github.com/johnson7543/design/actions/runs/39105725989)

- The candidate contains the same 19 archive entries. Only `README.md` changed;
  all 18 other files are byte-for-byte identical to the implementation CI archive.
- The final candidate archive passed isolated consumer checks with React 19.0.0
  and 19.2.8. Each run compiled six README examples and 16 demo examples and
  checked ESM/CommonJS imports, TypeScript, SSR, hydration, and Chromium
  mouse/touch/keyboard/action behavior.

  checksum matches the retained local archive and both React consumer reports.
  The complete CI log is retained alongside the archive as `verification.log`.
- On 2026-10-18, the maintainer confirmed that iPhone Safari and Android Chrome
  passed pull, aim, release, and return-animation checks. Device models and
  OS/browser versions were not supplied.
- Desktop Firefox and Safari qualification was pending at prerelease acceptance.
  The maintainer subsequently confirmed those checks on 2026-10-19; see the
  [stable release record](0-1-0.md) for the exact coverage.
