The current editable master is the native Blender scene with generated runtime
geometry, named-object OBJ, inventory, and rendered review image, as documented
in the [asset index](../../../../assets/design-qr/tokyo-tower/README.md).
The model was built and rendered using Blender 4.5.3 LTS. Keep exports synchronized
with the saved model; the authoring script can recreate the initial asset but
must not overwrite subsequent manual modeling edits during ordinary exports.

Any geometry refinement must preserve the full part inventory, complete surface
coverage, positive-area QR destinations, exact scan colors, reversible collapse,
and normal-speed readability. Compare the resulting views to registered sources
and continue to distinguish published measurements from interpretations.
