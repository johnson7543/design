# Shibuya asset sources

Original façade/vehicle geometry authored for DesignQR in Blender 5.2.1 LTS,
with source-aligned QFRONT/MAGNET contours. No downloaded 3D assets,
reference photos, external image textures, or user-uploaded logos are
included. The `.blend` file is an editable copy of the dedicated authoring scene;
ordinary package builds use the checked-in GLB and do not launch Blender.

`hachiko-sculpture.blend` contains the original reference-based seated Hachikō
sculpture and editable anatomical studies. Its dedicated
`scripts/blender/build-hachiko-sculpture.py` exporter writes compact indexed
geometry to `packages/designqr/src/designs/city/hachiko-sculpture-data.ts`.
The garden, pedestal, vector plaque and
geographic placement are documented in
[Hachikō statue and square](../../../docs/design-qr/hachiko-square.md).

`landmark-meshes.json` is generated by
`scripts/blender/prepare-shibuya-landmarks.mjs` from the shared runtime
architectural generator. It is authoring input, not a downloaded model or a
runtime network dependency. Regenerate it before running the Blender exporter.

Building contours are modified **3D都市モデル（Project PLATEAU）渋谷区（2025年度）**,
published by MLIT's Urban Bureau through
[Project PLATEAU](https://www.geospatial.jp/ckan/dataset/plateau-13113-shibuya-ku-2025).
Reuse follows the [PLATEAU site policy](https://www.mlit.go.jp/plateau/site-policy/)
(PDL 1.0 / CC BY 4.0-compatible terms). Projection, rotation, clipping, setbacks,
extrusion and original façade detail modify the source; its ownership remains
with the providers. See [building sources and limitations](../../../docs/design-qr/shibuya-architecture.md).

See the maintained [asset workflow](../../../docs/design-qr/shibuya-blender-assets.md)
for regeneration, coordinates, runtime ownership, packaging, and verification.
